# Uber Trip Analysis

An interactive Uber trip analysis dashboard built using **Python, Pandas, Matplotlib, and Streamlit**.

## Analysis

* Daily trip trends
* Peak booking hours
* Pickup location analysis
* Day-wise trip demand
* Passenger distribution
* Fare vs Distance
* Statistical analysis

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit

## Run the Project

```bash
pip install pandas numpy matplotlib streamlit
streamlit run uber-trip-analysis.py
```
